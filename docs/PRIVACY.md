# 数据与隐私说明

适用版本：书史 v1.4.29。更新日期：2026-10-14。

书史的账本、账户、流水、物品、存钱计划与设置保存在设备本地。当前版本不要求注册账户，不提供应用内云同步；应用 Manifest 不声明 INTERNET 权限。AI 与支付通知、无障碍自动识别功能已移除。

相机用于用户主动拍摄图片；系统照片选择器用于选择物品照片、账户或分类图片、背景图。通知权限用于记账提醒。旧 Android 的存储权限用于相应文件导出流程。系统生物识别或设备凭据用于应用锁，应用不保存生物识别模板。

完整备份、CSV 和 PDF 由用户主动导出到选择的位置。备份包含个人记录与照片，应由用户保管；完整备份文件没有应用提供的密码加密。应用锁不等于数据文件加密。

点击网页链接会通过外部浏览器访问 GitHub 等网站；主动分享文件或发送反馈会通过你选择的外部应用处理。外部服务有自己的数据规则。请不要在公开 Issues 中发送私人账本、完整备份或未经处理的截图。

Android 系统备份受本项目的 backup_rules / data_extraction_rules 和设备系统设置共同影响，不应把本说明理解为关闭所有系统级备份。清除应用数据或卸载通常会删除本地记录，操作前请做好完整备份。
