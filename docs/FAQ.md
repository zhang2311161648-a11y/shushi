# 常见问题

## 支持 iPhone、网页或云同步吗？

目前公开的是 Android 客户端源码与 APK，没有 iOS、网页客户端或账号云同步。数据保存在本机，换机使用完整备份。

## 有 AI、语音或自动读取支付记录吗？

当前版本已移除这些功能，以手动录入为主。旧版文档或安装包中的描述不适用于 v1.4.29。

## 安装时提示签名不同，怎么办？

确认下载的是本仓库 Releases 的正式 APK，并先导出当前应用的完整备份。自行编译的 release 使用你自己的密钥，不能覆盖其他密钥签名的同名包。Debug 包带 `.debug`，可与正式版并存。不要为解决冲突直接卸载含有未备份记录的应用。

## CSV 能恢复所有东西吗？

不能。CSV 用于流水整理或追加导入。完整迁移还涉及账户、账本、预算、物品、存钱计划、照片和设置，请使用完整备份。

## 焦虑抚平器会自动扣钱吗？

不会。它记录物品的拥有成本，物品表与收支流水分开。购买支出需另行记账。

## 「回本」是投资收益吗？

这里表示平均每天或每次使用的成本达到你设定的目标，不包含出售收益，也不是金融收益计算。

## 为什么应用锁没有弹出？

应用锁依赖系统生物识别或设备凭据。系统没有可用解锁方式时，当前实现会跳过锁定；请先配置设备锁。应用锁不是备份加密工具。

## 可以提交哪些问题？

闪退、余额计算、备份恢复、界面显示和功能建议均可在 Issues 提交。请附版本、Android 版本、复现步骤与预期结果，使用虚构数据复现。不要上传完整账本、签名文件或私人照片。
